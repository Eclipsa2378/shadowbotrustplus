# 🦀 ShadowBotRustPlus — Ваш умный помощник для кланов в Rust

Добавить бота в Discord - https://discord.com/oauth2/authorize?client_id=1465390250766635345&permissions=8&integration_type=0&scope=bot

**ShadowBotRustPlus** — это мощный Discord-бот, разработанный специально для кланов и команд в Rust. Он интегрируется с официальным Rust+ Companion API, предоставляя расширенный контроль над умными устройствами, уведомлениями о событиях и множество инструментов для координации, которые поднимут эффективность вашего клана на новый уровень.

## ✨ Ключевые возможности

### 🎮 **Полная интеграция с игрой**
- **Двусторонняя связь**: Отправляйте сообщения из Discord в игровой командный чат и наоборот.
- **Управление из любого места**: Используйте команды как через Discord (слэш-команды), так и прямо из внутриигрового командного чата.
- **Уведомления в реальном времени**: Получайте оповещения о ключевых игровых событиях прямо в Discord.

### 🚨 **Умные устройства и мониторинг**
- **Умные сигнализации (Smart Alarms)**: Настройте мгновенные оповещения при срабатывании датчиков.
- **Управление переключателями (Smart Switches)**: Включайте/выключайте электрические цепи удалённо через Discord.
- **Мониторы хранилищ (Storage Monitors)**: Отслеживайте содержимое ящиков и состояние шкафов в реальном времени.
- **Камеры наблюдения (CCTV)**: Быстрый доступ к кодам камер на монументах.

### 📊 **Инструменты для клана**
- **Отслеживание участников**: Видите, кто онлайн, оффлайн или в AFK. Получайте уведомления о подключениях/отключениях.
- **Клановые уведомления**: Умные оповещения о перемещениях команды, разделении по монументам и других важных событиях.
- **Система баз**: Отмечайте и отслеживайте до 9 квадратов вокруг вашей базы с уведомлениями о посторонних.
- **Задания и заметки**: Создавайте списки задач для команды и важные заметки, доступные всем участникам.

### 🛠 **Полезные команды и утилиты**
- **Информация о предметах**: Стоимость крафта, переработки, исследования и время распада для любого предмета.
- **Торговые автоматы**: Поиск предметов на рынке и подписка на выгодные предложения.
- **Таймеры и напоминания**: Установите таймеры для событий, крафта или рейдов.
- **Карта и маркеры**: Просматривайте карту сервера с монументами и устанавливайте собственные маркеры.
- **Трекинг игроков**: Интеграция с Battlemetrics для отслеживания игроков на сервере.
- **Переводчик**: Встроенный перевод текста между языками.

## 🎯 **Для кого этот бот?**
- **Для кланов**, желающих улучшить координацию и осведомлённость
- **Для команд**, которые хотят автоматизировать рутинные задачи
- **Для игроков**, ценящих своё время и желающих получить тактическое преимущество
- **Для всех**, кто ищет современный способ взаимодействия с игровым миром Rust

## 🚀 **Как начать использовать?**

1. **Пригласите бота** на свой Discord-сервер по этой ссылке  https://discord.com/oauth2/authorize?client_id=1465390250766635345&permissions=8&integration_type=0&scope=bot
